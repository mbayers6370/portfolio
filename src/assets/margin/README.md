Assets adapted from Matthew Bayers's `Social` project for its portfolio case study.

- Margin Aside: original custom lettering from `Social/public/fonts/margin-aside/`.
- Margin Editorial Geometry icons and motion: `Social/src/components/margin-icons/`; CC0 license included in `icons/LICENSE`.
- Sample photos: `Social/src/assets/fixtures/`, using fictional demo content.
- Inter: Latin variable font from `Social/public/fonts/inter/`; license included in `fonts/OFL.txt`.

The React snippets adapt the post-card conversation flip, feed ending,
brand brackets, animated icons, and profile presentation. Next.js, account data,
backend providers, and external requests are excluded from these local excerpts.
